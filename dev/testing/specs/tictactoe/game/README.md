# tictactoe

Tic-tac-toe in React. A freestanding sample game built test-first by the local agent.

- `test/`: Playwright acceptance tests (written first; do not edit)
- `src/TicTacToe.jsx`: the game component (default export)

```bash
npm ci
npm run dev   # play in the browser
npm test      # Playwright, starts its own Vite server on port 5179
```
